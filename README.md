# 🌟 Hazem Ziead | Personal Portfolio

> A modern personal portfolio showcasing my front-end development skills, applications, and responsive web design work.

---

## 🚀 Tech Stack

* **Core:** React / TypeScript / Vite
* **Styling:** CSS Modules / Tailwind CSS
* **Services:** EmailJS (direct contact form integration)

---

## ✨ Features

* 🎯 **Hero Section:** Introduction with clear call-to-action (CTA) buttons and resume access.
* 👨‍💻 **About Section:** Professional background, core competencies, and technical skills.
* 💼 **Projects Showcase:** Grid display of key projects featuring live demo and GitHub repository links.
* ✉️ **Contact Form:** Functional inquiry form powered by EmailJS.
* 📱 **Responsive Design:** Fully optimized across desktop, tablet, and mobile displays.

---

## 📁 Project Structure

```text
src/
├── assets/         # Static assets, images, and documents
├── components/     # UI components (Hero, About, Projects, Contact, Footer)
├── types/          # TypeScript interfaces and types
├── App.tsx         # Main application component
└── main.tsx        # Application entry point
